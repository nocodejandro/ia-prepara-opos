# ia-prepara-opos

## Video-clases de legislación

Para crear o modificar vídeos interactivos de estudio (Constitución, leyes, temario), usa la skill `video-clase` (`.claude/skills/video-clase/SKILL.md`) y lee `video-clases/README.md` antes de empezar. Cada tema es una carpeta en `video-clases/capsulas/<tema>/`. El resultado publicable es `video-clases/capsulas/<tema>/dist/`. Si falta algo por instalar, ejecuta `bash video-clases/instalar.sh`.
